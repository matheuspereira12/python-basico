# Curso de Python - Mundo 1 (Curso em Vídeo)

Repositório dedicado aos meus estudos, anotações e códigos de exercícios baseados no curso **Python 3 - Mundo 1**, ministrado pelo Professor Gustavo Guanabara.

## 📚 Sobre o Curso
O curso faz parte da iniciativa do Canal Curso em Vídeo e aborda os fundamentos iniciais da linguagem Python, incluindo:
* Manipulação de dados e tipos primitivos.
* Operadores aritméticos.
* Utilização de módulos.
* Condições básicas (`if`, `elif`, `else`).
