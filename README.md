# Python — Estudos e Exercícios

Repositório pessoal para estudos, práticas e exercícios de programação em Python 3, baseado principalmente nos cursos **Python 3 — Mundo 1, Mundo 2 e Mundo 3**, ministrados pelo professor **Gustavo Guanabara**, do canal **Curso em Vídeo**.

Os arquivos deste repositório registram exercícios e práticas realizados durante o aprendizado da linguagem Python.

## Conteúdo

### Mundo 1

Fundamentos da linguagem Python, incluindo conteúdos como:

* Primeiros programas em Python
* Variáveis
* Tipos primitivos
* Entrada e saída de dados
* Operadores aritméticos
* Operadores relacionais
* Operadores lógicos
* Módulos
* Condições
* Estruturas `if`, `else` e `elif`

### Mundo 2

Estruturas de controle e repetição, incluindo conteúdos como:

* Condições
* Condições aninhadas
* Estrutura `for`
* Estrutura `while`
* `break`
* Repetições
* Validação de condições
* Exercícios de lógica utilizando estruturas de controle

### Mundo 3

Estruturas compostas e organização de código em Python, incluindo:

* Tuplas
* Listas
* Dicionários
* Funções
* Módulos e pacotes
* Modularização
* Tratamento de erros e exceções
* Estruturas de dados
* Exercícios de lógica utilizando estruturas compostas

## Organização

Os exercícios estão organizados na pasta `exercises`.

Os arquivos seguem uma identificação numérica e uma descrição do exercício, mantendo uma organização baseada na sequência dos exercícios realizados.

Exemplo de nomenclatura:

`ex077_contando_vogais_em_tupla_v1.0.py`

O objetivo desta organização é manter os exercícios separados, identificáveis e fáceis de consultar.
